# Extended Library

The Extended Library picks up after the [Core Library](core-library.md) (CM-A–CM-E). These movements introduce more advanced timing, footwork, grip changes, dual-wielding, weapon variety, and full cinematic phrasing. Work through the Core Library first — Extended movements assume that foundation.
