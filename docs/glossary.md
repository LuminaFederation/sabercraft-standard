# Glossary

This glossary defines the working vocabulary of the SaberCraft Standard. Where a term has a page that introduces it in full, the term links there.

| Term | Definition |
|---|---|
| [SaberCraft Standard](standard.md) | The choreography standard maintained by Lumina Federation LLC and originated through SaberCraft. |
| Saberist | The general practitioner term within the SaberCraft Standard — anyone learning or performing SaberCraft Standard choreography. |
| Saberists | Plural of Saberist. |
| [Lumen](games/index.md) | A player within LUMINA Games specifically. Reserved for the Games layer — not used for general SaberCraft Standard practitioners (see Saberist). |
| Lumens | Plural of Lumen (LUMINA Games players). |
| [Duel](games/index.md) | Two Saberists performing together. |
| [CM](core/index.md) | Choreography Movement; a reusable segment of a saber duel. |
| [Telegraph](games/index.md) | A silent signal used to call or indicate a CM. |
| [Attack](notation/attacks.md) | A choreographed movement toward an intended target point. |
| [Parry](notation/parries.md) | A defensive response to an attack. |
| [Target](notation/targets.md) | A numbered line or point used to describe the intended direction of an attack. |
| [CM Library](core/index.md) | The official baseline movement library. |
| [LUMINA Games](games/index.md) | Optional structured game/scoring format. |
| [Knight](advancement/index.md) | A rank within the SaberCraft Knights program, an optional advancement system. |
