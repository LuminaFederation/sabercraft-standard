# Glossary

This glossary defines the working vocabulary of the Saber Standard. Terms are listed in roughly the order a new Saberist meets them, rather than alphabetically. Where a term has a page that introduces it in full, the term links there.

## The Saber Standard and its notation

These are the terms every Saberist uses, whether or not their school ever plays LUMINA Games.

| Term | Definition |
|---|---|
| [Saber Standard](standard.md) | The choreography standard maintained by Lumina Federation LLC and originated through SaberCraft. |
| Saberist | The general practitioner term within the Saber Standard — anyone learning or performing Saber Standard choreography. |
| Saberists | Plural of Saberist. |
| [Target](notation/targets.md) | A numbered line or point used to describe the intended direction of an attack. |
| [Attack](notation/attacks.md) | A choreographed movement toward an intended target point. |
| [Parry](notation/parries.md) | A defensive response to an attack. |
| [CM](core/index.md) | Choreography Movement; a reusable segment of a saber duel. |
| [CM Library](core/index.md) | The official baseline movement library. |
| [Telegraph](games/index.md) | A silent signal used to call or indicate a CM. |

## LUMINA Games and advancement

These terms belong to the optional layers built on top of the Saber Standard. A Saberist can read, write, and teach choreography without using any of them.

| Term | Definition |
|---|---|
| [LUMINA Games](games/index.md) | Optional structured game/scoring format. |
| [Lumen](games/index.md) | A player within LUMINA Games specifically. Reserved for the Games layer — not used for general Saber Standard practitioners (see Saberist). |
| Lumens | Plural of Lumen (LUMINA Games players). |
| [Duel](games/index.md) | Two Saberists performing together. |
| [Knight](advancement/index.md) | A rank within the SaberCraft Knights program, an optional advancement system. |
